# 🤖 ATS Resume Screener

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://ats-calculator-online.streamlit.app/)

An AI-powered tool that helps candidates and recruiters quickly evaluate **how well a resume matches a job description**.  
It uses **OpenAI GPT models** to provide both a **percentage match score** and a **structured evaluation** (strengths, gaps, suggestions).  

👉 Try it live here: [https://ats-calculator-online.streamlit.app/](https://ats-calculator-online.streamlit.app/)

---

## ✨ Features
- 📎 **Upload resume (PDF)** - extracts text automatically  
- 📄 **Paste job description** - compare any role against the resume  
- 📊 **ATS Match %** - keyword and relevance score with missing skills  
- 🧠 **Evaluation mode** - recruiter-style feedback with strengths, risks, and improvement suggestions  
- 🧹 **Clear button** - reset session instantly  
- ⚙️ **Model controls** - pick GPT model, temperature, and token limit
